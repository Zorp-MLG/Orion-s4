• Memory: 512KB Flash, 96KB SRAM

• Package: LQFP64

# What is orion s4?

# How do I replicate it?

1. Download PCB files in Assets folder of the repo.
2. Fabricate it via a PCB company, or your own CNC machine.
3. Buy all modules/component's.
4. Solder It all together one by one.
5. download firmware files in Firmware folder of the repo.
6. flash it via SWD pins(only for the main firmware, after that you can do your code via USB C)
7. Finish!
